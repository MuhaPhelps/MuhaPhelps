# CAE Manager — система управления инженерными расчётами

Итоговый индивидуальный проект на Flutter Web.

Тема: **«Система управления инженерными расчётами»**.

Проект рассчитан на требования итоговой работы **на оценку 4**:
- 8 связанных сущностей;
- связи 1:1, 1:N и N:M;
- CRUD по всем сущностям;
- валидация форм;
- слои модели / репозитории / состояние / экраны / виджеты;
- адаптивность 360–1920 px;
- состояния loading / data / empty / error;
- регистрация и вход;
- 3 роли с разными разделами;
- защищённые маршруты и скрытие недоступных разделов;
- поиск, 3 фильтра, сортировка и пагинация на стороне PocketBase;
- параметры отбора отражаются в URL;
- сессия восстанавливается после перезагрузки.

## Быстрый запуск на Windows

### Самый простой вариант

Дважды щёлкните `START_ALL.bat`. Он откроет PocketBase в отдельном окне, подождёт 5 секунд и затем запустит Flutter Web.

Если хотите запускать по отдельности:

### 1. Запустить сервер

Дважды щёлкните:

`START_BACKEND.bat`

При первом запуске скрипт автоматически скачает официальный PocketBase v0.40.4, после чего миграция создаст базу данных и тестовые записи.

API: `http://127.0.0.1:8090/api/`

Панель PocketBase: `http://127.0.0.1:8090/_/`

Superuser панели:
- `admin@cae.local`
- `Admin123!`

### 2. Запустить Flutter

В отдельном окне запустите:

`START_APP.bat`

или вручную:

```powershell
flutter pub get
flutter run -d chrome --web-port=5555 --dart-define=API_BASE_URL=http://127.0.0.1:8090
```

## Учётные записи приложения

### Инженер

- `Engineer123!`

### Проверяющий
- `reviewer@cae.local`
- `Reviewer123!`

Доступен отдельный раздел: Проверки.

### Руководитель
- `manager@cae.local`
- `Manager123!`

Доступны: Заказчики, Инженеры, Проекты.

## Сброс базы

Если нужно получить исходные тестовые данные заново:

1. остановите PocketBase;
2. удалите папку `backend/pb_data`;
3. снова запустите `START_BACKEND.bat`.

Миграция автоматически создаст схему и тестовые данные заново.
